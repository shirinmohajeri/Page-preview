# 🚀 Logbot Website Demo

A modern, responsive landing page showcasing an Industrial IoT platform concept.
Built using **HTML, CSS, and JavaScript**, this project demonstrates a clean UI with animated hero sections and interactive sliders.

## ✨ Features

* 🎯 Clean and modern UI design
* 📱 Fully responsive layout
* 🎞️ Hero section with automatic slider
* 🖱️ Interactive navigation and controls
* 🎨 Smooth animations and transitions

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling and animations
* **JavaScript (Vanilla)** – Interactivity

---

## 📂 Project Structure

```
├── index.html   # Main HTML file
├── style.css    # Styling and layout
└── script.js    # Slider functionality
```

---

## ⚙️ How It Works

* The hero section includes **two slides** with dynamic content.
* JavaScript updates:

  * Title
  * Subtitle
  * Visual elements
* Slides automatically change every **4 seconds** and can also be controlled manually.
